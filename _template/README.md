# Template de Proposta V4

## Como criar uma nova proposta

1. Copie esta pasta para `/{nome-cliente}/` na raiz do repositório
2. Preencha o `client-config.json` com os dados do cliente
3. Renomeie `master.html` para `index.html`
4. Aplique as personalizações no HTML (cores, textos, logos, dados)
5. Valide no browser (acordeões, animações, responsivo, acentos)
6. Commit e push para `main` — deploy automático via GitHub Pages

## URL final

```
https://v4bilinski.github.io/propostas-bilinski/{nome-cliente}/
```

## Convenção de nomes

- Pasta: lowercase, separado por hífen, sem acentos
- Exemplos: `acme-corp`, `empresa-exemplo`, `mwm-latam`
